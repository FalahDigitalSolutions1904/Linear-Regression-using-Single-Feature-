# Simple Linear Regression (Single Feature)

This project implements a foundational Simple Linear Regression model to predict outcomes based on a single variable using a medical dataset.

## Overview
- **1.ipynb**: The main Jupyter Notebook containing data exploration, visualization, and the linear regression model implementation.
- **medical.csv**: The dataset used for training and testing the model.

## Getting Started
Install the required dependencies and launch Jupyter Notebook to run the analysis.
